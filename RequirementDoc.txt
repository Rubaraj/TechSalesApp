# TechSales App - Requirements Document

## Project Overview
Health Insurance selling application for managing leads, plans, enrollments, and sales operations.

## Development Architecture

### Technology Stack
- **Frontend**: React 19 with TypeScript
- **Build Tool**: Vite 7
- **Styling**: Tailwind CSS v4 with custom theme system
- **Routing**: React Router DOM v7
- **State Management**: React Context API
- **Data Storage**: JSON files (simulating backend - will be replaced with real backend later)

### Design Requirements
- Responsive design: Mobile, tablet, and desktop support
- Light and dark mode toggle
- Multi-theme support: Default (Orange), Aetna (Purple), Humana (Green)
- Service layer pattern: Separate service files for data access
- Component-based architecture with reusable UI components

## Admin Functionalities

### User Management
- Super admin can access all admin functionality
- Create/edit/delete users (agents)
- Assign users to departments
- Role-based access control (RBAC) system
- Permission management per module and action

### Department Management
- Create multiple departments
- Tag users to departments
- Department-based access control

### System Settings
- Theme selection (Default, Aetna, Humana)
- Light/Dark mode toggle
- System configuration

### Dashboard
- Tile-based navigation system for all modules
- Insights on enrollments done by users
- Lead lifecycle overview (progress bar and charts)
- Agent performance metrics
- Productivity dashboard for admins

## Modules in the Application

### Lead Management
**Status**: ✅ Implemented

**Lead Data Fields**:
- Personal Information: FirstName, LastName, DOB, Age (Auto-calculated), Gender (Male/Female), Email, Address1, Address2, ZipCode, State, County, City, Phone
- Demographics: Ethnicity, Race
- Medicare Information: Medicare Number, Medicaid ID, Part A Date, Part B Date
- Lead Status: New Lead → Contacted Lead → Appointment Schedule → Enrollment in progress → Enrolled → Dropped / Lost lead
- **Source** (Required): Web, Call, Event, Referral, Vendor
- Flags: Permission to Contact, Existing Aetna Member, Tobacco Usage

**Lead Lifecycle**:
- Visual timeline in Lead Detail page (horizontal layout)
- Progress tracking through stages
- Lifecycle charts in Dashboard

**Lead Features**:
- Create, List, View individual lead information
- Multiple tabs: Overview, Pharmacies, Drugs, Documents, Activity
- Tag SOA (PBA), EKIT (PBKit), Pharmacy, Drug data, Plan recommendations
- Lead autocomplete component for quick selection

### Plan Listing
**Status**: ✅ Implemented

**Plan Features**:
- List different types of plans
- Filter by carrier (Aetna, Humana, UnitedHealthcare, Cigna, Blue Cross Blue Shield, etc.)
- Filter by product type (MAPD, MA, PDP, Medsup, ANC)
- Filter by plan type (HMO, PPO, DSNP, CSNP, etc.)
- Filter by category (Medicare Advantage, PDP, Medsup, ANC)
- Contract year selector

**Plan Information**:
- Individual plan detail page with tabs:
  - Overview: Plan details, cost summary
  - Benefits: Grouped by category with availability indicators (tick/cross)
  - Premiums: Regional premium breakdown with Medicaid/LIS adjustments
  - Documents: Summary of Benefits, Evidence of Coverage, Formulary, Provider Directory, Annual Notice of Change
- Star ratings display
- Plan comparison capability

**Plan Visibility Rules** (To be implemented):
- Plans hidden/shown based on Lead age, zip code, and agent access level
- Premium adjusted based on Medicaid and LIS eligibility

### Pharmacy
**Status**: ✅ Implemented

**Features**:
- Search pharmacies by name
- Filter by zip code, state, county
- Tag pharmacy to lead (maximum 3 pharmacies per lead)
- Pharmacy detail modal with contact information and services
- Grid and list view modes

**Future Enhancement**:
- Google Maps integration for visual location display
- Map-based pharmacy selection

### Drug
**Status**: ✅ Implemented

**Features**:
- Search drugs by brand or generic name
- Auto-complete while typing
- Tag drugs to lead (unlimited number)
- Drug details: dosage, quantity, frequency
- Drug detail modal with formulary information, tier, restrictions
- Grid and list view modes

### YOY (Year-Over-Year) Plan Comparison
**Status**: ✅ Implemented

**Features**:
- Compare plans from previous year (2024 vs 2025)
- Side-by-side comparison view
- Summary cards for premium, star rating, and total changes
- Detailed comparison table with change highlighting
- Impact badges (Improved, Increased Cost, Changed)

### Medicaid Eligibility (State Assistance Check)
**Status**: ✅ Implemented

**Features**:
- Eligibility check form: FirstName, LastName, DOB, Gender, Medicare Number, Medicaid ID, SSN, Medicaid State
- Eligibility verification result display (Eligible/Not Eligible)
- Eligibility type indicator (Full, QMB, SLMB, QI)
- Records list with verification dates and expiration
- Stats cards (Total, Eligible, Not Eligible, Expiring Soon)
- Available as individual page and integrated in plan listing

### LIS Eligibility (Plan Subsidy Check)
**Status**: ✅ Implemented

**Features**:
- Low Income Subsidy eligibility check
- Form: FirstName, LastName, DOB, Gender, Medicare Number
- LIS level determination (1-4)
- Copay level display
- Records list with level badges
- Stats cards (Total, Eligible, Full Subsidy, Partial Subsidy)
- Available as individual page and integrated in plan listing

### SOA (Scope of Appointment) → PBA (Plan Briefing Appointment)
**Status**: ✅ Implemented (Renamed to PBA)

**Features**:
- Schedule appointments when lead doesn't want to enroll directly
- Lead selection with autocomplete
- Products to discuss selection
- Meeting summary and timing
- Status tracking: Pending, Sent, Completed, Expired
- Send to beneficiary functionality
- Download PDF capability

### EKIT (Email Kit) → PBKit (Plan Bundle Kit)
**Status**: ✅ Implemented (Renamed to PBKit)

**Features**:
- Send plan information via email
- Lead selection with autocomplete
- Plan selection for kit
- Tracking status: Pending, Sent, Opened, Clicked
- Resend functionality
- Plan count badges

### Plan Recommendations
**Status**: ✅ Implemented

**Features**:
- AI-powered plan recommendations based on beneficiary profile
- Lead selection with Medicaid/LIS status display
- Filter by plan type, max premium, minimum stars
- Match score calculation (0-100%)
- Drug coverage and pharmacy network percentages
- Estimated annual cost calculations
- Plan highlight badges (premium, coverage, benefits)
- Expandable plan cards with detailed information

## Data Storage Structure

### Runtime Data (src/data/runtime/)
- `leads.json` - Lead records
- `users.json` - User/Agent accounts
- `roles.json` - Role definitions with permissions
- `departments.json` - Department information
- `enrollments.json` - Enrollment records
- `pba.json` - Plan Briefing Appointment records
- `pbkit.json` - Plan Bundle Kit records
- `medicaidEligibility.json` - Medicaid eligibility records
- `lisEligibility.json` - LIS eligibility records
- `members.json` - Member accounts
- `memberAppointments.json` - Member appointments

### Lookup Data (src/data/lookup/)
- `planInformation.json` - Plan details (80+ plans from multiple carriers)
- `premiumInformation.json` - Plan pricing with Medicaid/LIS adjustments
- `benefitData.json` - Plan benefits with availability indicators
- `starRatings.json` - Plan quality star ratings
- `drugData.json` - Drug formulary catalog
- `pharmacyData.json` - Pharmacy locations
- `zipStateCounty.json` - US geographic data (Zip, State, County mapping)
- `planreccdata.json` - Plan recommendation mappings
