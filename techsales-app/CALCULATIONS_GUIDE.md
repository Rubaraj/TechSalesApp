# Dashboard Calculations Guide

This document explains the two key financial calculations used in the TechSalesApp dashboards:
**Agent Commission** and **Savings Breakdown**.

Both are displayed as flippable toggle cards on the dashboard — click the card to flip between the summary (front) and the detailed breakdown (back).

## 1. Agent Commission Calculation

### What It Does

Calculates how much commission an agent earns from enrollments based on a **percentage of the enrollment premium**.

### Commission Rates

| Product Type | Agent Rate | Carrier Rate |
|-------------|-----------|-------------|
| MAPD / MA   | 15%       | 75%         |
| PDP         | 15%       | 75%         |
| Medsup      | 20%       | 80%         |
| ANC         | 20%       | 80%         |

### Formula

```
Agent Commission = Enrollment Premium x Agent Rate
Carrier Revenue  = Enrollment Premium x Carrier Rate
```

### Functions Used

- **`calculateAgentRevenueForEnrollment(enrollment, plan)`** — returns commission for a single enrollment
- **`calculateRevenueBreakdown(enrollments, plans)`** — returns `{ agentRevenue, carrierRevenue, totalRevenue }` across all enrollments

### Worked Example

Suppose an agent has these 4 enrollments:

| # | Product | Monthly Premium |
|---|---------|----------------|
| 1 | MAPD    | $150.00        |
| 2 | PDP     | $40.00         |
| 3 | Medsup  | $200.00        |
| 4 | ANC     | $75.00         |

**Step-by-step calculation:**

```
Enrollment 1 (MAPD):   $150.00 x 0.15 = $22.50   (agent)  |  $150.00 x 0.75 = $112.50  (carrier)
Enrollment 2 (PDP):    $40.00  x 0.15 = $6.00    (agent)  |  $40.00  x 0.75 = $30.00   (carrier)
Enrollment 3 (Medsup): $200.00 x 0.20 = $40.00   (agent)  |  $200.00 x 0.80 = $160.00  (carrier)
Enrollment 4 (ANC):    $75.00  x 0.20 = $15.00   (agent)  |  $75.00  x 0.80 = $60.00   (carrier)
```

**Result:**

```
Agent Revenue   = $22.50 + $6.00 + $40.00 + $15.00 = $83.50
Carrier Revenue = $112.50 + $30.00 + $160.00 + $60.00 = $362.50
Total Revenue   = $83.50 + $362.50 = $446.00
```

### Toggle Card Display

- **Front (Commission Tracker):** Shows `$83.50` as "Estimated This Month" with a % change vs last month
- **Back (Commission Structure):** Shows the rate table (15%/20%) and the agent's total estimate

## 2. Savings Breakdown Calculation

### What It Does

Calculates the estimated monthly cost savings generated by all enrollments. This uses a **mixed model** — some products have a fixed dollar saving per enrollment, while others use a percentage of premium.

### Savings Rates

| Product Type | Rate Type  | Rate              |
|-------------|------------|-------------------|
| MAPD / MA   | Fixed      | $20 per enrollment |
| PDP         | Fixed      | $18 per enrollment |
| Medsup      | Percentage | 20% of premium    |
| ANC         | Percentage | 20% of premium    |

### Formula

```
For MAPD/MA:  Savings = $20 (flat, per enrollment)
For PDP:      Savings = $18 (flat, per enrollment)
For Medsup:   Savings = Premium x 0.20
For ANC:      Savings = Premium x 0.20

Total Savings = Sum of all enrollment savings
```

### Functions Used

- **`calculateMonthlyCostSavings(enrollments, plans)`** — returns a single total savings number
- **`calculateCostSavingsBreakdown(enrollments, plans)`** — returns detailed breakdown:
  ```typescript
  {
    mapd:  { count, savings, rate: 20 },      // rate is a number ($)
    pdp:   { count, savings, rate: 18 },      // rate is a number ($)
    medsup:{ count, savings, rate: '20%' },   // rate is a string (%)
    anc:   { count, savings, rate: '20%' },   // rate is a string (%)
    total: number
  }
  ```

### Worked Example

Suppose we have these 5 enrollments:

| # | Product | Monthly Premium |
|---|---------|----------------|
| 1 | MAPD    | $150.00        |
| 2 | MAPD    | $180.00        |
| 3 | PDP     | $40.00         |
| 4 | Medsup  | $200.00        |
| 5 | ANC     | $75.00         |

**Step-by-step calculation:**

```
Enrollment 1 (MAPD):   $20.00  (fixed — premium is NOT used)
Enrollment 2 (MAPD):   $20.00  (fixed — premium is NOT used)
Enrollment 3 (PDP):    $18.00  (fixed — premium is NOT used)
Enrollment 4 (Medsup): $200.00 x 0.20 = $40.00
Enrollment 5 (ANC):    $75.00  x 0.20 = $15.00
```

**Breakdown result:**

```
MAPD/MA:  count = 2,  savings = $40.00   (2 x $20)
PDP:      count = 1,  savings = $18.00   (1 x $18)
Medsup:   count = 1,  savings = $40.00   (1 x 20% of $200)
ANC:      count = 1,  savings = $15.00   (1 x 20% of $75)
─────────────────────────────────────────
Total Savings = $40.00 + $18.00 + $40.00 + $15.00 = $113.00
```

### Toggle Card Display

- **Front (Total Cost Savings):** Shows `$113.00` with label "From multi-platform savings"
- **Back (Savings Breakdown):** Shows each product line item:
  ```
  MAPD/MA (2 x $20)      $40.00
  PDP (1 x $18)           $18.00
  Medsup (1 x 20%)        $40.00
  ANC (1 x 20%)           $15.00
  ───────────────────────────────
  Total Savings           $113.00
  ```
- The back side displays an "Approx" badge since these are estimates

## Key Differences Between the Two Calculations

| Aspect | Agent Commission | Savings Breakdown |
|--------|-----------------|-------------------|
| Purpose | How much the agent earns | How much the client saves |
| MAPD/MA rate | 15% of premium | $20 flat per enrollment |
| PDP rate | 15% of premium | $18 flat per enrollment |
| Medsup rate | 20% of premium | 20% of premium |
| ANC rate | 20% of premium | 20% of premium |
| Uses premium? | Always (all products) | Only for Medsup and ANC |
| Output | Agent + Carrier + Total revenue | Savings per product + Total |

---

## Common Logic Notes

1. **Plan lookup:** Both calculations build a `Map<planId, Plan>` for O(1) lookups, then iterate through enrollments to find the matching plan.
2. **Missing plan:** If an enrollment's `planId` doesn't match any plan, that enrollment is skipped (no error thrown).
3. **Missing premium:** If `enrollment.premium` is `undefined` or `null`, it defaults to `0`.
4. **Rounding:** All final amounts are rounded to 2 decimal places using `Math.round(value * 100) / 100`.
5. **Product type matching:** `'MAPD'` and `'MA'` are treated identically in all calculations. Unknown product types are silently skipped.
6. **Enrollment type/period:** Neither `enrollmentType` (New, Plan Change, etc.) nor `enrollmentPeriod` (AEP, OEP, etc.) affects the calculations — only product type and premium matter.
